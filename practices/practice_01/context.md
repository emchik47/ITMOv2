# Контекст

AS IS: учебный кейс — AI‑помощник ревьюера PR. Вход — diff одного PR. Задача помощника: кратко описать изменение, выделить до трёх рисков с привязкой к файлу/строке и доказательством, предложить список проверок. Решение принимает человек; approve/merge/изменения кода запрещены.

Команда: студент выполняет задания в своём форке. Рабочий агент OpenCode в режиме Build готовит документы и запускает эксперименты.

Источники: practices/practice_01/README.md и TRAINING_PR.diff. Ограничения: тестовые запуски без инструментов; история рабочего чата не передаётся.

## Context Pack

Факты: вход — только diff; выход — описание, до 3 рисков с доказательством и проверки. Ограничения: не одобрять и не менять код. Примеры «хорошего» и «плохого» комментариев заданы в README.
