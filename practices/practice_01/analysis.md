# Процесс

AS IS:
- Ревьюер вручную читает diff и пишет комментарии произвольно.
- Риски часто без ссылок и проверок; часть выводов недоказуема.

## TO BE
- Агент получает diff и возвращает: описание, ≤3 риска (файл/строка/доказательство) и список проверок.
- Ревьюер запускает проверки и принимает решение.

Нотация: текстовая диаграмма переходов.

1. Input: diff → 2. Analyze: извлечь изменения → 3. Detect: риски (≤3) → 4. Propose: проверки → 5. Output → 6. Human review.
