# Проблема и метрики

Пользователь: инженер‑ревьюер PR.

Проблема: в условиях ограниченного времени сложно быстро выявить существенные риски по diff без ложных утверждений.

Цель: повысить доказательность комментариев и воспроизводимость проверок.

## Метрики

- Доля комментариев с точной ссылкой на файл/строку и фактом (целевое ≥ 90%).
- Не более 3 рисков на PR, каждый с проверяемым доказательством.
- Для каждого риска есть воспроизводимая проверка (шаги/команда).
