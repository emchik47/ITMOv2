# Few-shot

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Артефакт Практики 1: practices/practice_01/prompts.md (Master Prompt v1)
- Что хотим улучшить: повысить воспроизводимость за счёт примеров «хорошего» и «плохого» результата; уточнить формат рисков и проверок.

## Примеры

### Хороший результат

Summary: Удалён неиспользуемый метод в модуле utils/logging.

Risks:
- file: src/utils/logging.py, line: 42, title: Удаление функции используется в тестах, evidence: "- def format_event(event: dict) -> str:" показано удаление, check: запустить pytest tests/test_logging.py::test_format_event и ожидать падение при отсутствии функции.
- file: src/app.py, line: 15, title: Лишний импорт после удаления, evidence: "+ from utils.logging import format_event" остался импорт, check: запустить app и убедиться, что импорт не ломает запуск; удалить импорт при необходимости.

Checks:
- pytest -q tests/test_logging.py::test_format_event
- запуск приложения: python -m app

### Плохой результат

Summary: Код можно улучшить.

Risks:
- Нет ссылок на файл/строку и цитат из diff.

Checks:
- «Добавьте тесты», без конкретных шагов.

## Запрос

Сформируй для Master Prompt два примера — хороший и плохой — в заданном формате. Хороший пример обязан содержать: file, line, evidence (прямая цитата из diff) и воспроизводимые проверки. Плохой — типичные ошибки: общие формулировки, отсутствие ссылок, отсутствие воспроизводимых шагов. Не выдумывай код репозитория, используй абстрактные, но структурно корректные примеры.
