# Chain of Verification

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Проверяемый черновик или утверждение:
  «Любое утверждение подтверждать цитатой из diff и ссылкой на строку.»

## Запрос на проверку

Проверь, достаточно ли формулировки Master Prompt, чтобы исключить ложные ссылки и придуманные цитаты. Предложи минимальное уточнение, если есть лазейки: например, цитата без точного указания диапазона строк или ссылка на несуществующую строку.

## Вопросы и результаты проверки

| Вопрос | Источник или проверка | Результат |
|---|---|---|
| Может ли модель сослаться на «строку 9999» вне фактического диапазона diff? | Проверка по формату diff (номера хунк-диапазонов). | Такая ссылка возможна без явного запрета; нужно требование указывать точный хунк и смещённую строку внутри него. |
| Достаточно ли одной цитаты без указания hunk, если файл многократно менялся? | Формат unified diff с несколькими hunks в одном файле. | Недостаточно; нужна привязка к конкретному hunk или точному номеру исходной/новой строки. |
| Должен ли evidence совпадать побайтно с цитатой из diff? | Сравнение строк с учётом префиксов '+', '-', ' '. | Да, необходимо требование побайтного совпадения, включая префиксы контекста. |

## Исправленный результат

Уточнение в Master Prompt:
- Evidence: прямая цитата из diff, побайтно совпадающая с соответствующей строкой (включая префикс '+', '-', ' '), с указанием файла, номера hunks (формат @@ -a,b +c,d @@) и точного номера строки в контексте hunks.
